# PlayMatch

PlayMatch helps you find people to play sports with. Find nearby courts and fields, post and join pickup games, add friends, book time slots, and chat with the players in your games.

## What it does

- **Find places to play:** a map of courts and fields near you, from OpenStreetMap plus community-added venues.
- **Pickup games:** post a game with a time and a player cap (2–30 players); each game has a group chat visible only to joined players.
- **Friends:** search players by username and send friend requests.
- **Booking:** reserve a time slot at a venue; overlapping bookings are blocked.
- **Profiles:** age, height, skill level, and highest level played, with per-sport positions.

Sports: basketball, soccer, American football, tennis, pickleball, and table tennis. Golf is coming next.

## How to build

1. Open `BrickLess.xcodeproj` in Xcode.
2. Select a simulator or a connected iPhone.
3. Build and run.
